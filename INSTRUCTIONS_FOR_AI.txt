# PredictTheFuture — AI Agent Instructions

## Current Project Status
- **Contract:** `contracts/prediction_market.py` is a GenVM Intelligent Contract implementing prediction markets with AI-powered resolution.
- **Frontend:** Next.js 16 + React 19 app with Tailwind CSS 4. Supports wallet connection, market creation, betting, and resolution.
- **Network:** GenLayer Bradbury Testnet (Chain ID 4221)

## Key Architecture Details
1. **Contract Storage:** Uses `TreeMap[bigint, str]` with JSON serialization for market data, and separate TreeMaps for bet tracking and pool balances.
2. **AI Resolution:** Uses `gl.vm.run_nondet_unsafe(leader_fn, validator_fn)` where the leader fetches evidence from the resolution URL and an LLM evaluates the outcome. Validators independently verify via Optimistic Democracy.
3. **Frontend Adapter:** `src/lib/contract.ts` abstracts all contract reads/writes. Falls back to demo mode when `NEXT_PUBLIC_CONTRACT_ADDRESS` is not set.
